# SUBSYSTEMS :

Swerve Subsystem.java == Otomatik/Manuel sürüş hareketleri, hız ayarları.

AlgeaIntakeSubsystem.java == Topu içeri alma, atma ve periyodik şekilde tekrar etme (Otomatik şekilde), hız konrolü manuel.

ElevatorSubsystem.java  == Asansörün  çalışması, hız kontrolü manuel, motor durdurma, periyodik hareketlerle.

IntakeMoverSubsystem.java == Manuel hareketler, motor durdurma.

IntakeSubsystem.java == zamanlayıcı, top içeri alındığında motor durdurma, topu atma, periyodik şekilde yapma.

ObjectDetectorSubsystem.java == Bir objenin olup olmadığını kontrol ediyor.

RotarySwitchSubsystem.java == Radyo veya iletişim kanalları olabilir (channel)

StatusLED.java == Işık yanma konuşlları, varsayılan ışık yok, verilen parametreye göre (sanırım ittifaklar) kırmızı veya mavi oluyor.
